# 📱 SafeZone

SafeZone היא אפליקציה חכמה למצבי חירום, שנבנתה ב-React Native ו-Expo Go, ומציעה פתרון כולל ונגיש לכלל האוכלוסייה במצבי חירום. האפליקציה מספקת מידע בזמן אמת על מקלטים, שירותי עזרה ותמיכה רגשית, ומאפשרת חיבור מהיר בין אזרחים, מתנדבים וארגונים.

---

## 🎯 מטרת האפליקציה

האפליקציה נועדה לשמש כפתרון כולל למצבי חירום, תוך שילוב טכנולוגיה מתקדמת ונגישות גבוהה לכלל האוכלוסייה.  
היא מתמקדת בשיפור היכולת של אזרחים להגיב במהירות וביעילות, על ידי אספקת מידע רלוונטי ומעודכן על מקלטים, שירותי עזרה ותמיכה רגשית.  
המטרה היא לא רק להקל על ההתארגנות הפיזית, אלא גם לטפל בצרכים הרגשיים והחברתיים של המשתמשים, וליצור תחושת ביטחון גם בזמנים של אי-ודאות.  
האפליקציה שואפת לחבר בין קהילות מקומיות לארגונים ומתנדבים בצורה פשוטה ואינטואיטיבית, כך שתיווצר רשת תמיכה חזקה ומשמעותית.  
בנוסף, היא שמה דגש על יצירת כלים ללמידה והדרכה, שיעזרו להכין את המשתמשים למצבי חירום עתידיים, ויעודדו מודעות ואחריות קהילתית בשגרה ובחירום.

---

## 🚀 תכונות עיקריות

## 🛠️ התקנה והרצה

1. שיבוט הפרויקט:
   ```bash
   git clone https://github.com/TalRefael/SafeZone.git
   ```

2. מעבר לתיקיית הפרויקט:
   ```bash
   cd SafeZone
   ```

3. התקנת התלויות:
   ```bash
   npm install
   ```

4. הרצת האפליקציה:
   ```bash
   npx expo start
   ```
